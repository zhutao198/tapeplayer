# 原理图评审报告 — TapeBook 音频播放器（小智音响）V1.0

- **评审对象**：`hardware/V1/audio_player.txt`（PADS Logic V9.5 ASCII，2 页：1.POWER / 2.ESP32）
- **评审依据**：原理图网表（解析自 `audio_player.txt`）、固件 `main/config.h`（V1.3）、BOM（`BOM-PAudio_player-V1.0-260808.xlsx`）、元器件规格书（`hardware/datasheet/`：ESP32-S3-WROOM-1、TP4056、MT3608、BL8039、MX66100T、MAX98357A、LMV321、WS2812 等）
- **评审日期**：2026-08-11
- **修订记录**：2026-08-11 根据用户反馈逐项复核规格书后修订：
  - S1（TP4056 TEMP 接地）→ **非缺陷**：UMW C725790 规格书明确允许 TEMP 直地（仅禁用温度监测）。
  - H1（LMV321 共模）→ **已闭环**：原 TI `LMV321IDBVRG4` 为 RRO 会越界；换 UMW/友台 `LMV321IDBVR`（轨到轨输入）后消除。
  - M1（TF-015 pin9）→ **已确认**：pin9 为机械 CD 开关，非数据线。
  - M2（R15/MT3608）→ **误判修正**：R15 接 U5.6(OC 电流限制脚) 而非 EN；OC 可浮空，DNP 合法；EN(U5.4) 实际直连 VSYS（常开 Boost）。
  - M3（电阻取值）→ **撤销**：用户已核对原理图与 BOM 一致。
  - L2/SD_MODE 复核（第三轮）：ESP32-S3 GPIO4 **非 strapping、上电无内部上拉**（原"内部上拉≈high"假设错）；固件 IO4 强驱输出正确。用户指正设计意图为 **(Left/2+Right/2) 求和单声道**（MAX98357 规格书：0.16~0.77V 窗口 = B0~B1，即单喇叭立体声），而非 Left 模式——判断成立。原 R19=1M 串联 + 内部 100k 下拉使 SD_MODE≈0.278~0.322V，典型条件下正确落入该窗口，却**紧贴 B0 关断阈值上限(0.355V)**，B0 偏高的单体将掉入 Shutdown 无声 → 定为 **H2（中，批量裕度风险）**。**R19 已整改为 634k**（规格书 Table 6 RLARGE，VDDIO=3.3V 专用值，使 VSD≈0.418~0.480V 居中，远离 0.355V 关断阈值），实测应落入求和单声道窗口中段，保留设计意图并消除批量风险。

## 四、关键问题详细说明与整改建议

### S1 — TP4056 TEMP 接地：合规设计选择（非缺陷）【原"严重"已降级】

**现象**：网表显示 `U2.1 (TEMP) → GND`；符号 `pin1=TEMP`，与标准 TP4056 MSOP-8 物理引脚 1 一致。

**规格书结论（UMW C725790，即 BOM 料号）**：datasheet 原文 —— *"the TEMP pin can be directly grounded without monitoring the battery temperature"*（TEMP 可直接接地以禁用电池温度监测）。即：**接地仅关闭温度监测功能，充电正常进行**，不会挂起。

**结论**：原评审将"TEMP 接地→永久冷故障→不充电"判为严重缺陷，但该行为针对的是其他 TP4056 克隆料号；对实际使用的 **UMW C725790** 不成立。**本项非缺陷。**

**保留提示（见 L4）**：禁用温度监测等于失去 NTC 过温保护，为设计权衡；料号一旦更换须复核 TEMP 行为。

### H1 — LMV321 输入共模越界：经换料（UMW 轨到轨输入）解决【原"高"已闭环】

**现象**：运放接成电压跟随器（U10.1=IN+，U10.3/4=IN−/OUT 经 R36→BAT_DET），电源 U10.5=+3.3V。IN+ 来自 R34/R35 对 Q2 源极跟随输出的分压（≈0.708×VBAT）；VBAT=4.2V 时 IN+≈2.97V。

**根因（原设计料号）**：TI `LMV321IDBVRG4` 为轨到轨**输出**（RRO），但输入**非**轨到轨，VICR=0~(V+−1.0V)。3.3V 供电时上限仅 **2.3V**，IN+ 在 VBAT>3.25V 即越界，输出饱和→BAT_DET(IO1) 读值失真→电量显示异常/恒满。

**解决（用户决策）**：改用 **UMW/友台 `LMV321IDBVR`**，其规格书明确为**轨到轨输入+输出**（输入电压范围 −0.1V~5.6V @VS=5.5V，单电源 2.1V~5.5V）。在 3.3V 供电下 IN+ 最高≈2.97V 仍在轨到轨范围内，**共模越界问题解决**。

**硬性约束**：BOM/采购必须指定 **UMW 友台 RRI 版本**；若被 TI `LMV321IDBVRG4`（RRO）或其他非 RRI 料号替代，H1 问题将复现。

**建议复核（低成本）**：仍可在 VBAT=3.3V/3.8V/4.2V 三点实测 U10.4 输出是否线性跟随，作为换料后的验收。

### H2 — MAX98357 SD_MODE 偏置裕度不足（中，原 L2 升级）【复核新发现】

**现象**：SD_MODE(U8.4) 经 R19(**634k，已整改；原 1M**) 串联接 IO4(GPIO4)；R20(上拉至 +3V3_MCU) 为 DNP；MAX98357 内部含 100k 下拉(RPD，datasheet 92~108k / typ 100k)。固件 `main.cpp:788-796` 将 GPIO4 配置为推挽输出并 `gpio_set_level(GPIO4,1)` 拉高(3.3V)。

**节点电压计算**（分压：3.3V 源 → R19 → SD_MODE 节点 → RPD → GND）：
- R19=1M（整改前）：SD_MODE = 3.3V × RPD/(1M + RPD) ≈ **0.278~0.322V**（随 RPD 92~108k 变化）
- R19=634k（**已整改，当前**）：SD_MODE ≈ **0.418~0.480V**（规格书 Table 6 RLARGE，VDDIO=3.3V 专用值）；**实测 0.432V（R19 功放端），V3.3 端≈3.3V，完全吻合计算，确认落入求和单声道窗口中段、远离 B0 关断阈值 0.355V**

**规格书 Table 5（绝对阈值，与 VDD 无关）**：B0=0.08/0.16/0.355V，B1=0.65/0.77/0.825V，B2=1.245/1.4/1.5V。模式映射：
- VSD > B2(1.4V) → **Left**（仅左声道）
- B2 > VSD > B1 → Right
- B1 > VSD > B0 → **(Left/2 + Right/2) 求和单声道** ← 用户设计的单喇叭立体声
- VSD < B0 → **Shutdown（静音）**

**结论（用户指正后修正）**：
1. 用户的**设计意图正确**：求和单声道对应 0.16~0.77V 窗口（B0~B1），即单喇叭播放立体声混音，与 `config.h` 注释"Mono"一致（非 Left 模式）。
2. R19=1M 时 VSD≈0.278~0.322V，**典型条件下（B0≈0.16）正确落入求和单声道窗口，有声且符合预期**；
3. **但裕度不足**：VSD 下限 0.278V 已**低于 B0 上限 0.355V**——对 B0 阈值偏高的单体（B0 > 实测 VSD），SD_MODE 落在 B0 以下 → **Shutdown 完全无声**，存在批次性不响风险。且 1M 不在 datasheet 推荐电阻序列。
4. 若改 R19=634k（规格书 Table 6 的 RLARGE，VDDIO=3.3V 专用值），VSD≈0.418~0.480V，距 B0_max(0.355) 余量 +0.063V、距 B1_min(0.65) 余量 0.17V，**稳健居中于求和单声道窗口**，保留用户设计意图且消除批量风险。

**整改（已实施①，保留求和单声道设计意图）**：
1. **保留求和单声道（已整改）**：R19 已改为 **634k**（原 1M）。SD_MODE≈0.45V 居中，单体一致性好，符合用户"单喇叭立体声"意图。固件 IO4 保持拉高即可。
2. **改纯 Left 模式（备选，会改变音频行为）**：R19 改 0Ω 或 ≤10k（IO4 直驱），拉高时 SD_MODE≈3.3V>1.4V→Left（仅取左声道）。注意这会改变混音方式，与设计意图不同，非必要不取。
3. **不推荐保留 1M**：取值不在 datasheet 推荐序列，且最贴近 B0 关断阈值，批量风险最大。

> 说明：无论取 634k 还是 0Ω，boot 期 IO4 未配置时 SD_MODE 被内部 100k 下拉置低 → Shutdown（静音/低耗），安全无风险。

**附：用户要求核实的两点**
- **ESP32-S3 GPIO4 上电内部上拉？** 否。GPIO4 非 strapping 脚（芯片 datasheet Table 3-1 仅列 GPIO0/3/45/46 为 strapping），复位默认输入、无内部上/下拉。原 L2 "上电内部上拉≈high" 不成立；但固件已 `pull_up_en=GPIO_PULLUP_DISABLE` 并**强驱输出**，比依赖上拉更可靠，故功能不受影响。
- **固件代码处理方式？** 正确。`main.cpp:788-796`：GPIO4=GPIO_MODE_OUTPUT、禁上下拉、`gpio_set_level(GPIO4, MAX98357_SD_MODE_LEVEL=1)`。确定性拉高；上电至配置前的窗口内，SD_MODE 由 MAX98357 内部 100k 下拉保持低→Shutdown(静音/低耗)，无风险。唯一需改的是外部 R19 取值（见上）。
