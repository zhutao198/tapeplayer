### 关键链接陷阱

1. `.c` 文件必须用 `gcc` 编译 (而非 `g++`), 否则 C-linkage 符号被 C++ 名称修饰, 与 `extern "C"` 声明冲突
2. mock 头 (`nvs.h`/`esp_partition.h`) 必须包 `extern "C" { ... }`, 否则 C++ 链接失败
3. NVS `_once` 错误注入模式: 第一次返回错, 第二次清掉错 (用于测 settings 自动恢复路径)
4. 运行时需 mingw64/bin 在 PATH (`build_and_run.bat` 已自动设置)
