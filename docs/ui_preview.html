操作映射（无双击、无锁定，依据固件 main.cpp）：
播放 短按 = 播放/暂停　播放 长按 = 切换模式（顺序 / 列表循环 / 单曲循环）
停止 短按 = 停止　停止 长按 = 进入浏览（上一首/下一首 滚动选曲，播放 确认，停止 退出）
浏览中 停止 长按 = 给选中曲加书签　浏览中 上一首/下一首 长按 = 连续移动曲目（越按越快）
非浏览态 上一首/下一首 长按 = 音量 − / +
快退/快进 短按（非浏览态） = ±10 秒　长按 = 快退 / 快进
浏览中 快退/快进（显示名 上翻页/下翻页） 短按 = 上/下翻页（跳 6 曲）　长按 = 跳到列表头 / 尾
UI 底部按键顺序即物理顺序：快退 播放 快进 停止 ｜ 上一首 下一首
走带四键（快退/播放/快进/停止）居中成组，符合磁带机直觉；选曲键（上一首/下一首）在右侧。
已移除「按键锁定」功能；原双击操作改为长按 / 移入浏览界面，触发更可靠。
